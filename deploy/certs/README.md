# Дополнительные доверенные сертификаты MAX

Если MAX API требует дополнительный доверенный CA, помести проверенный сертификат в формате PEM в эту папку и укажи MAX_CA_BUNDLE=/app/certs/имя-файла.pem в серверном .env. Файлы этой папки, кроме README, исключены из Git и образа Docker, но доступны контейнеру через read-only mount. Стандартные доверенные корни сохраняются. Проверка TLS не отключается.

Актуальные требования: https://dev.max.ru/docs-api/methods/POST/subscriptions
