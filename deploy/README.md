# Размещение сайта и мини-приложения

Для запуска на Windows через Docker Desktop и закреплённый адрес ngrok используй отдельную инструкцию [DOCKER-NGROK.md](../DOCKER-NGROK.md) и `compose.ngrok.yaml`. Ниже описан другой вариант: Linux-сервер с собственным доменом, Caddy и основным `compose.yaml`.

1. Настрой DNS домена на IP сервера и открой входящие TCP 80/443 (UDP 443 необязателен). Домен и сервер нужно получить отдельно.
2. Скопируй проект из приватного репозитория на сервер. В корне скопируй `.env.example` в `.env` и заполни DOMAIN, ACME_EMAIL, POSTGRES_PASSWORD, JWT_SECRET. Для секретов сгенерируй отдельные hex-строки командой `python -c "import secrets; print(secrets.token_hex(32))"`. Hex-пароль подходит для DATABASE_URL без дополнительного кодирования. Поля MAX можно заполнить позже.
3. Выполни из корня проекта:

```bash
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose logs --tail=80 app
```

PostgreSQL и uploads сохраняются в именованных томах. Миграции выполняются перед стартом API. База и API не публикуют свои порты наружу; Caddy обслуживает сайт и API по одному HTTPS-домену. Caddy автоматически запрашивает сертификат. JWT и `.env` не попадают в образ. Query-параметры скачивания сертификатов не записываются access-log сервера.

4. Проверь `https://твой-домен.ru/health` и открой сайт. Создай первого администратора:

```bash
docker compose exec app python -m scripts.create_admin
```

Контейнерная БД изначально новая. Твои локальные пользователи и события не переносятся автоматически. Для переноса нужна резервная копия PostgreSQL и папка uploads; не подключай контейнер к БД старого проекта.

5. Подключи бота по [MAX.md](../MAX.md). Для `.env` в Docker PUBLIC_BASE_URL формируется из DOMAIN. Для Python без Docker PUBLIC_BASE_URL задаётся в `beckend/.env`.

Обновление кода: `git pull`, затем `docker compose up -d --build`. Перед обновлением схемы сохраняй резервную копию базы и uploads. Для просмотра только настроек без вывода секретов используй `docker compose config --quiet`.

Приложение штатно работает без MAX. По умолчанию функции бота выключены, пока не указаны его токен, имя и секрет webhook. Не запускай несколько worker без общего хранилища идентификаторов webhook, если нужно подавлять повторы между процессами.
