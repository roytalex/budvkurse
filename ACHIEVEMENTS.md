# Достижения и рейтинг

Чаты и напоминания убраны из интерфейса и API. Подключение бота MAX будет отдельным этапом. Календарь, личные планы, избранное и запись на мероприятия продолжают работать.

## Как подтвердить посещение

1. Участник записывается на событие через сайт.
2. После окончания организатор открывает «Мои мероприятия» → событие → «Участники».
3. Нажимает «Посетил» напротив тех, кто действительно участвовал.
4. Если ошибся, нажимает «Снять отметку».

Администратор может подтверждать посещения через «Управление». Посторонний организатор и ученик не могут менять чужие отметки. Подтверждать себе участие и начислять награды организатору собственного события нельзя. Для событий с внешней регистрацией или без записи список посетителей автоматически не импортируется: сейчас достижения работают для участников, записавшихся на сайте.

Повторное нажатие не добавляет второе посещение. Запись и сохранение в календарь не начисляют баллы. После начала опубликованного события участник не может отменить запись: это сохраняет список для проверки посещения.

## Награды

| Достижение | Условие | Баллы |
|---|---|---|
| Первый шаг | 1 мероприятие | 10 |
| Исследователь | 5 мероприятий | 30 |
| В центре событий | 10 мероприятий | 60 |
| Всегда в курсе | 25 мероприятий | 150 |
| Вызов принят | 1 олимпиада | 20 |
| Олимпийский темп | 3 олимпиады | 60 |
| Знаток | 10 олимпиад | 150 |

Олимпиады входят и в общий счётчик событий. Каждая достигнутая награда даёт баллы один раз; баллы разных наград суммируются. Например, 10 событий, из которых 3 олимпиады, дают 180 баллов и 5 наград.

## Общий рейтинг

Раздел «Рейтинг участников» виден всем вошедшим пользователям, включая учеников, организаторов и администратора. В мобильной версии он находится в нижнем меню; «Мои достижения» доступны через профиль. Нажми на участника рейтинга, чтобы посмотреть его награды.

Участвуют активные аккаунты хотя бы с одним подтверждённым посещением завершённого опубликованного события. Сортировка: сначала сумма баллов за достижения, затем число посещений. При одинаковом результате место общее; порядок внутри такого места устойчивый, по id пользователя. Рейтинг выдаётся страницами по 20 участников.

Показываются имя, посещения, достижения и баллы. Email и другие закрытые данные не публикуются. Если организатор снимает отметку, событие отменено/удалено или перенесено в будущее, счётчики и рейтинг пересчитываются при следующей загрузке раздела. Изменение категории события также влияет на счётчик олимпиад.

## API и база

Все пути ниже начинаются с `/api/v1`, нужен access-токен.

| Метод и путь | Результат |
|---|---|
| `GET /me/achievements` | Мой прогресс, награды, баллы, место |
| `GET /achievements/leaderboard?page=1&limit=20` | Страница общего рейтинга |
| `GET /users/{user_id}/achievements` | Достижения активного участника |
| `PUT /events/{event_id}/attendance/{user_id}` | `{"attended":true}` — подтвердить, `false` — снять |

Таблица `attendance`: id, user_id, event_id, confirmed_by, confirmed_at. Пара user_id/event_id уникальна. Время подтверждения хранится с часовым поясом. Удаление события удаляет его отметки. Награды и рейтинг вычисляются из посещений, поэтому не расходятся с текущими данными.

Миграция `0003` добавляет таблицу посещений. Старые сообщения и настройки напоминаний не удаляются из базы: они недоступны приложению, а миграции `0001`/`0002` сохраняются для совместимости установок.

Перед запуском обновления из папки `beckend`:

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 4174
```
