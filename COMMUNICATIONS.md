# Сообщения, напоминания и мобильный интерфейс

## Как пользоваться

- Звёздочка `*` рядом с полем означает **необязательное поле**. В форме есть пояснение. Для публикации очного события по-прежнему нужны адрес и координаты, даже если черновик можно сохранить без них.
- В карточке опубликованного мероприятия нажми **«Напомнить»**. Выбери время: в момент начала, за 15/30 минут, час, 3 часа, день или неделю. Событие автоматически попадёт в личные планы.
- **«Не напоминать»** отключает уведомление, сохраняя событие в планах. Удаление события из планов тоже убирает напоминание.
- Вверху сайта и в профиле есть **«Напоминания»**. Счётчик обновляется при открытом сайте примерно раз в 30 секунд. После переноса мероприятия время напоминания пересчитывается; отменённые события не напоминаются. Пропущенные уведомления доступны до недели после начала мероприятия.
- Это уведомления **внутри сайта**, без email и фоновых push. При закрытом сайте уведомление можно прочитать после следующего входа.
- В карточке мероприятия нажми **«Написать организатору»**. По одному мероприятию создаётся один диалог с этим участником. Организатор отвечает в разделе **«Сообщения»**. Только два участника видят историю; роль администратора не открывает чужие переписки.
- Сообщения обновляются примерно раз в 5 секунд, пока раздел открыт. Старую историю можно догрузить кнопкой «Предыдущие сообщения». Счётчик непрочитанных уменьшается после просмотра последних сообщений. Повтор отправки после сетевого сбоя не создаёт дубль.
- После удаления мероприятия переписка сохраняется с названием события, но без ссылки на удалённую карточку. Неактивному пользователю новые сообщения отправить нельзя.
- На телефоне список диалогов и переписка открываются последовательно. Вернуться к списку можно стрелкой. Сообщения и напоминания доступны кнопками вверху и из профиля; остальные разделы — через нижнюю навигацию и профиль.

## Бэкенд

Новые таблицы: `conversations`, `messages`. В `plans` добавлена nullable-колонка `reminder_read_for`, хранящая время уже прочитанного напоминания. Все новые ручки требуют входа:

| Метод | Путь после `/api/v1` | Назначение |
|---|---|---|
| GET | `/me/communications/summary` | Число непрочитанных сообщений и наступивших напоминаний |
| GET | `/me/conversations` | Мои диалоги с пагинацией |
| POST | `/events/{event_id}/conversation` | Открыть или создать диалог с организатором |
| GET | `/conversations/{id}/messages` | Последние сообщения; `before_id` — история, `after_id` — новые |
| POST | `/conversations/{id}/messages` | Отправить `body` (1–4000 символов) и `client_id` (UUID) |
| POST | `/conversations/{id}/read` | Прочитать до `message_id`, принадлежащего этому диалогу |
| GET | `/me/reminders` | Наступившие напоминания, с пагинацией |
| POST | `/me/reminders/{event_id}/read` | Отметить напоминание прочитанным, передав его `due_at` |
| PUT | `/me/plans/{event_id}` | Сохранить `reminder_minutes_before`; `null` отключает напоминание |

Слои кода: `db/models/messages.py`, `schemas/communications.py`, `crud/communications.py`, `services/communications.py`, `api/routes/communications.py`. Фронтенд: `communications.js`, `communications.css`, `optional-fields.js`.

## При переносе на другой компьютер

Перед запуском новой версии в папке `beckend` выполни миграцию:

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
```

Миграция `0002` добавляет таблицы и колонку, не удаляя существующие события и пользователей. Перед обновлением рабочей базы сделай резервную копию. Затем запусти Uvicorn как обычно и обнови сайт через Ctrl + F5. Go Live и основной адрес FastAPI продолжают работать с теми же ручками.
