# Напоминания на сайте

Открой опубликованное событие → «Настроить напоминание». Выбери начало события, 15 минут, час, день или неделю до него. Событие добавится в личный календарь. Это не записывает тебя участником: регистрация выполняется отдельно.

Колокольчик в верхней панели и пункт «Напоминания» в меню открывают список. При наступлении срока появится уведомление внутри сайта; проверка выполняется раз в минуту, пока вкладка видима. После возвращения на вкладку выполняется новая проверка. После подключения MAX в профиле сервер отправляет сообщения-напоминания через бота даже при закрытом сайте. Инструкция: [MAX.md](MAX.md).

«Прочитано» сохраняется на сервере. Если организатор перенёс начало, прежняя отметка прочтения не скрывает новое напоминание. Завершённые, отменённые и удалённые события не напоминаются. «Выключено» убирает уведомление, сохраняя план. Удаление события из личного календаря удаляет его напоминание.

Все ручки требуют Bearer-токен, работают только с планами текущего пользователя. Префикс `/api/v1`:

| Метод и путь | Действие |
|---|---|
| `PUT /me/plans/{event_id}` | `{"reminder_minutes_before":60}` — включить за час; `null` — отключить; `{}` — сохранить прежнюю настройку |
| `GET /me/plans` | Личные планы, включая `reminder_minutes_before` |
| `GET /me/reminders?page=1&limit=20` | Предстоящие и текущие опубликованные события с включённым напоминанием; `reminder_at`, `unread`, `read` |
| `PUT /me/reminders/{event_id}/read` | Тело `{"starts_at":"2030-10-27T10:00:00Z"}` с точным значением из ответа; 204 при успехе, 409 при переносе или ещё не наступившем сроке |
| `DELETE /me/plans/{event_id}` | Удалить план вместе с напоминанием |

Допустимое время — целое число от 0 до 10080 минут. Таблица `plans` уже содержит `reminder_minutes_before` и `reminder_read_for`; для доставки в MAX миграция 0005 добавляет состояние отправки и таблицу подключений. При новой установке по-прежнему выполняется `alembic upgrade head`. Изменение настройки сбрасывает прочтение, повторное сохранение той же настройки его сохраняет.

Код: `beckend/schemas/plans.py`, `beckend/services/personal.py`, `beckend/services/reminders.py`, `beckend/api/routes/personal.py`, `frontend/reminders.js`. Проверки: `beckend/tests/test_reminders.py`, `frontend/tests/reminders.test.cjs`.

После внутренней регистрации создаётся напоминание за час, если плана ещё нет. Существующий выбор сохраняется. Отмена регистрации выключает напоминание. Для сообщений MAX нужно явно подключить аккаунт из мини-приложения.
