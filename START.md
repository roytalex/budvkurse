# Будь ВКурсе — запуск сайта целиком

На этом компьютере сайт и API настроены вместе. База проекта — **budvkurse_app** на локальном PostgreSQL. Существующая roytalex относится к другому приложению и не изменялась.

## Открыть сайт

1. Убедись, что PostgreSQL запущен.
2. Дважды нажми `start.cmd` в папке проекта. Если сайт уже запущен на 4174, второй запуск не нужен.
3. Открой **http://127.0.0.1:4174/**.

Для входа администратором открой файл **.admin-access.txt** в папке проекта. В нём записаны email и случайный пароль, созданные для тебя. Этот файл и `.env` исключены из Git и архива для передачи проекта.

Посетитель нажимает «Зарегистрироваться», выбирает тип аккаунта «Ученик» или «Организатор» и создаёт аккаунт. Организатору сразу доступен раздел «Мои мероприятия» и самостоятельная публикация. Администратор может удалить неподходящее событие. Без входа события, справочники, карта, календарь и личные данные недоступны — проверка есть и в интерфейсе, и в API.

Если сервер запускаешь сам, из папки `beckend`:

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 4174
```

Сайт и API используют один адрес, отдельный статический сервер больше не нужен. Для остановки нажми Ctrl+C в терминале сервера. Если сервер запущен фоном помощником, его PID записан в `.runtime/server.pid`.

## Первое настоящее мероприятие

1. Войди администратором. В «Управление» уже есть три города и пять тем. Школы добавь там же, указав настоящие название и адрес. Выдуманные школы и старые демонстрационные события не перенесены.
2. Открой «Мои мероприятия» → «Создать мероприятие».
3. Заполни название, описание, город, дату начала и окончания. Можно загрузить обложку.
4. Для очного мероприятия укажи площадку, адрес и **выбери точку на карте**. Для онлайн-события укажи ссылку.
5. Выбери способ записи: на этом сайте, на сайте организатора или без предварительной записи. Это запись на конкретное мероприятие; аккаунт сайта нужен во всех случаях.
6. Сохрани черновик → «Опубликовать». Организатор публикует самостоятельно, без предварительного одобрения.
7. После публикации событие появится в ленте и календаре. Очное событие с координатами появится на карте, если попадает в её видимую область и выбранные фильтры.

Форма использует время устройства и отправляет на сервер дату с часовым поясом. Календарь также показывает время устройства. Многодневные события отмечаются во всех пересекаемых днях; событие, заканчивающееся ровно в полночь, не занимает следующий день.

## Как изменения связаны между разделами

| Действие | Результат |
|---|---|
| Изменить опубликованное событие | Изменения сразу обновят ленту, карту, календарь и личные планы; повторное одобрение не требуется |
| Изменить координаты | После сохранения метка появится в новом месте |
| Изменить даты | После сохранения событие появится в соответствующем месяце календаря |
| Добавить в избранное | Сохранится в аккаунте; повторное нажатие уберёт событие |
| Добавить в планы | Появится в режиме «Мои планы» календаря; это не запись участником |
| Записаться | Сервер проверит сроки, класс и свободные места; запись появится в «Мои записи» |
| Отменить свою запись | Место освободится, запись сменит статус |
| Администратору удалить любое событие | Событие и связанные записи участников, планы, избранное и история проверки удалятся из базы |
| Удалить новый черновик | Он удалится из базы и списка собственных событий |
| Отменить опубликованное | Оно исчезнет из ленты и общей карты; в личных планах останется с пометкой «Отменено» |
| Удалить используемый город/тему | Сервер объяснит конфликт и сохранит данные |
| Деактивировать школу | Она исчезнет из выбора, существующие связи и история сохранятся |

Чтобы увидеть изменения другого пользователя, нажми «Обновить» или заново открой раздел. Собственные изменения обновляют интерфейс сразу после ответа сервера. Карта подгружает события при перемещении; календарь — при смене месяца. Все страницы данных загружаются, включая подборки более 100 событий.

## Роли

- **Ученик:** профиль, интересы, просмотр, избранное, планы и запись.
- **Организатор:** создание, самостоятельная публикация, изменение и отмена своих событий, список участников; удаление своих черновиков.
- **Администратор:** просмотр всех событий в «Управление → Все мероприятия», удаление неподходящих событий с подтверждением, управление справочниками.

Организатор выбирает свою роль при регистрации на сайте. Если нужно изменить роль уже существующего ученика, выполни из папки `beckend`:

```powershell
.\.venv\Scripts\python.exe -m scripts.set_role user@example.com organizer
```

После назначения пользователь входит заново. При регистрации доступны только ученик и организатор. Создать администратора через публичную форму нельзя.

## Что убрано из интерфейса

Фиктивный профиль, старые демонстрационные мероприятия, локальное создание событий в браузере, неработающая «Регистрация (демо)» и кнопки обещаний push-уведомлений. Все пользовательские изменения сохраняются в PostgreSQL. На чистой базе лента пустая, пока организатор или администратор не опубликует реальное событие.

Подложка карты нейтральная, без подписей стран; перемещение ограничено границами мира. Для загрузки подложки нужен интернет, а список событий приходит с локального API.

## Перенос проекта

Архив содержит исходники, но не пароль администратора, `.env`, виртуальное окружение, загруженные файлы или содержимое базы. На другом компьютере создай окружение, установи `beckend/requirements-lock.txt`, настрой `.env` и примени миграции по инструкции в `beckend/README.md`. Создай собственного администратора. Для переноса существующих данных отдельно нужны дамп PostgreSQL и папка `beckend/uploads`.

API доступен под `/api/v1`, Swagger — `/docs`. Вход через форму сайта не переносится автоматически в Swagger: для проверки ручек получи access_token через `/auth/login` и вставь в Authorize.

Восстановление пароля по почте и рассылка напоминаний не реализованы. Кнопок, обещающих эти функции, в интерфейсе нет.


## Населённые пункты, школы и удобная карта

- В фильтрах, профиле и форме мероприятия нажми «Найти по России». Введи название города, посёлка, села или деревни, при необходимости добавь регион и нажми «Найти».
- После выбора населённого пункта нажми «Найти школу». Ищи школу, лицей или гимназию по названию или номеру. Проверь название и адрес результата.
- Выбранные места сохраняются в справочниках PostgreSQL. Данные мероприятия остаются привязаны к обычным `city_id` и `school_id`.
- В форме мероприятия выбор школы подставляет её название, адрес и известные координаты. Если координат нет, найди адрес или поставь точку на карте. Метку можно перетаскивать.
- Организатор и администратор могут нажать «Не найдено? Добавить вручную». Для населённого пункта укажи регион и выбери центр на карте. Для школы нужны название, населённый пункт и адрес.
- Карта событий разворачивается на весь экран, показывает твоё местоположение по разрешению браузера и ищет адреса. Масштаб — кнопками +/−, жестом двух пальцев или Ctrl + колесо. Escape сворачивает большую карту.

Источник внешнего поиска — [Photon](https://github.com/komoot/photon) и [OpenStreetMap](https://www.openstreetmap.org/copyright). Это поиск по России, а не предварительно загруженный полный официальный реестр: в открытых данных бывают пропуски, результаты ограничены наиболее подходящими вариантами. Уточняй запрос; сохранённые варианты доступны без внешнего поиска. Весь справочник автоматически не скачивается. Для полноты официального реестра требуется отдельная актуальная лицензированная выгрузка адресов и образовательных организаций.

Запросы отправляются только по кнопке «Найти», а не при каждом нажатии клавиши. Сервер кэширует их 15 минут и ограничивает внешние обращения одним в 1,1 секунды на процесс. Публичный сервер Photon допускает умеренное использование и не гарантирует доступность. Для локального проекта запускай один процесс Uvicorn; для большой нагрузки настрой собственный/договорной сервер совместимого API через `GEOCODER_URL` в `.env`, например `GEOCODER_URL=http://localhost:2322/api/`. Секреты, токены входа и профиль пользователя внешнему поиску не передаются; передаётся поисковый запрос и координаты выбранного населённого пункта.

## Карта и календарь

Подложка карты — OpenFreeMap (данные OpenStreetMap), без API-ключа. Нужны интернет и поддержка WebGL в браузере. Стиль `frontend/neutral-map.json` содержит дороги, здания, парки и воду без географических подписей и политических границ. Библиотеки MapLibre GL JS 5.6.2 и адаптер Leaflet 0.1.3 лежат локально в `vendor`, лицензии рядом. При ошибке подложки есть кнопка повтора; данные событий остаются доступны.

Календарь открывает текущий месяц. В карточке опубликованного события нажми «Показать в календаре» — откроется его дата со сбросом фильтров. Кнопка «Ближайшее событие» ищет следующее событие с текущими фильтрами за пределами месяца. Режим «Мои планы» показывает только добавленные в планы события, а не все записи участника.

## Go Live в VS Code

Настроен адрес http://127.0.0.1:5500/frontend/index.html. Открой всю папку budvkurse, запусти FastAPI на 4174 и нажми Go Live. Подробная инструкция: [GO-LIVE.md](GO-LIVE.md).

## Достижения и рейтинг

Организатор открывает своё завершённое мероприятие, нажимает «Участники» и отмечает посетивших. Ученик видит прогресс в «Мои достижения», все пользователи — общий рейтинг. Подробнее: [ACHIEVEMENTS.md](ACHIEVEMENTS.md). Перед запуском обновления выполни `python -m alembic upgrade head` в beckend. Чаты и напоминания отключены; бот MAX пока не подключён. Звёздочкой по-прежнему отмечены необязательные поля.
